# MagicLab Manager

Настольное приложение для внутреннего учёта заказов Magic Lab Detailing.
Работает локально на Windows, без браузера и сервера. Текущая версия: **1.3.1**.

## Возможности

- Клиенты, автомобили и история обслуживания.
- Услуги с ценами для четырёх классов автомобилей.
- Заказы, расчёт стоимости и времени, предоплата и история статусов.
- Расписание и экспорт календарного файла ICS.
- Роли руководителя, администратора и мастера, назначение заказов.
- Осмотр ЛКП: схема кузова, дефекты, толщина покрытия и фотографии.
- Статистика, журнал действий, заказ-наряд, PDF и CSV.
- Полные ZIP-копии базы и фотографий с проверкой перед восстановлением.

Мастер видит только назначенные ему заказы. Руководитель управляет прайсом,
сотрудниками и резервными копиями. Клиентского доступа нет.

## Технологии

Python 3.11+, PySide6, SQLAlchemy 2.x, SQLite, pytest, PyInstaller.
Версии зависимостей закреплены в `requirements.txt`.

## Установка и запуск

Нужны Windows 10/11 x64 и Python 3.11 или новее. Интернет нужен для установки
зависимостей; после установки приложение работает автономно.

Запустите `install_windows.bat`, затем `run_windows.bat`.
Либо выполните в PowerShell из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m app.main
```

При первом входе создайте аккаунт руководителя: укажите имя, логин и пароль.
Общего пароля для рабочей базы нет. Сотрудников добавляют в «Пользователях».

Встроенные услуги и цены — **тестовые**. Перед рабочими заказами замените их
на настоящий прайс в разделе «Услуги». Учебные записи из настроек не следует
добавлять в рабочую клиентскую базу.

## Структура

```text
launcher.py            точка входа для сборки
app/
  main.py              запуск Qt и вход в систему
  config.py            пути и версия
  database.py          соединения и сессии SQLite
  models.py            модели SQLAlchemy
  migrations.py        обновление схемы
  repositories/        запросы и операции с данными
  services/            расчёты, права, заказы, осмотр и копии
  ui/                  окна, страницы и диалоги Qt
  resources/           логотип, значки, схемы и перевод
tests/                 автоматические проверки
tools/                 подготовка ресурсов и учебных данных
docs/                  руководства
```

## Данные и резервные копии

При запуске создаются `data/`, `backups/` и `exports/`.
База: `data/magiclab.db`. Фотографии: `data/inspection_photos/`.
Эти каталоги не входят в Git.

В «Настройках» руководитель создаёт полную ZIP-копию. Копируйте её на отдельный
носитель. Восстановление проверяет архив, создаёт страховочную копию,
заменяет текущие данные и требует повторного входа.

Не используйте одну базу одновременно с нескольких компьютеров. Перед
обновлением заполненной папки обязательно создайте резервную копию.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Последний полный прогон: **261 тест пройден**. Проверяются расчёты, формы,
снимки цен, роли, статусы, календарь, осмотр и резервное копирование.
Тесты используют отдельные базы, а не рабочие данные.

## Сборка EXE

```powershell
.\build_exe.bat
```

Скрипт запускает тесты и собирает папку `dist/MagicLabManager/`.
Передавать нужно всю папку, не только EXE. Python на целевом компьютере
не требуется. База создаётся рядом с EXE.

EXE не подписан сертификатом издателя. В последней проверке новой поставки
запуск был заблокирован политикой Windows с ошибкой 4551; запуск именно этой
сборки на другом компьютере пока не подтверждён. При блокировке обратитесь
к администратору, не отключайте защиту Windows.

## Возможные ошибки

- Нет доступа к папке: перенесите приложение в «Документы», не в Program Files.
- Неверный пароль: проверьте логин; пароль сотрудника сбрасывает руководитель.
- Программа уже запущена: проверьте открытые окна; не удаляйте файл блокировки
  при работающем приложении.
- Внутренняя ошибка: сохраните описание действий и `data/magiclab.log`.
  Не публикуйте базу клиентов, фотографии и журнал без проверки содержимого.

# MagicLab Manager

Настольное приложение для внутреннего учёта заказов Magic Lab Detailing.
Работает локально на Windows, без браузера и сервера. Текущая версия: **1.3.1**.

## Возможности

- Клиенты, автомобили и история обслуживания.
- Услуги с ценами для четырёх классов автомобилей.
- Заказы, расчёт стоимости и времени, предоплата и история статусов.
- Расписание и экспорт календарного файла ICS.
- Роли руководителя, администратора и мастера, назначение заказов.
- Осмотр ЛКП: схема кузова, дефекты, толщина покрытия и фотографии.
- Статистика, журнал действий, заказ-наряд, PDF и CSV.
- Полные ZIP-копии базы и фотографий с проверкой перед восстановлением.

Мастер видит только назначенные ему заказы. Руководитель управляет прайсом,
сотрудниками и резервными копиями. Клиентского доступа нет.

## Технологии

Python 3.11+, PySide6, SQLAlchemy 2.x, SQLite, pytest, PyInstaller.
Версии зависимостей закреплены в `requirements.txt`.

## Установка и запуск

Нужны Windows 10/11 x64 и Python 3.11 или новее. Интернет нужен для установки
зависимостей; после установки приложение работает автономно.

Запустите `install_windows.bat`, затем `run_windows.bat`.
Либо выполните в PowerShell из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m app.main
```

При первом входе создайте аккаунт руководителя: укажите имя, логин и пароль.
Общего пароля для рабочей базы нет. Сотрудников добавляют в «Пользователях».

Встроенные услуги и цены — **тестовые**. Перед рабочими заказами замените их
на настоящий прайс в разделе «Услуги». Учебные записи из настроек не следует
добавлять в рабочую клиентскую базу.

logo.png — исходный логотип, предоставленный пользователем 04.09.2026.
Файл не перерисован. При показе Qt совмещает чёрную подложку с тёмной поверхностью.
Если файла нет, приложение показывает текст «Magic Lab».

../icons/magiclab.ico — многоразмерная упаковка того же логотипа для Windows.
Исходный PNG не изменён. Пропорции, цвета, надпись и чёрная подложка сохранены;
для квадратного формата ICO добавлены прозрачные поля сверху и снизу.
Размеры: 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 пикселей.
Повторная подготовка: python tools/build_icon.py (использует установленный Qt).
